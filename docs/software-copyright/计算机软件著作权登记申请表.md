### 开发目的

面向内容审核平台、学术出版机构和企业合规审查场景，提供本地部署的中英文AI生成文本检测能力。系统通过统计语言模型特征、语言学文体特征、编码器语义特征和Binoculars交叉困惑度四个维度的融合分析，对输入文本进行AI生成概率评估，支持文本粘贴和PDF文件上传两种检测模式。

### 主要功能

本软件面向AI生成内容检测场景，提供从文本输入、多阶段检测、结果展示到分段分析的一体化功能。系统通过FastAPI提供RESTful API服务，同时提供Web前端界面，支持中英文双语自动识别和差异化检测策略。

**四阶段级联检测管线**：系统采用统计特征提取（Stage 1）、语言学文体特征提取（Stage 1b）、编码器分类（Stage 2）和Binoculars零样本检测（Stage 3）四个阶段，按语言类型（中文/英文）自动路由至不同的检测路径。

**统计特征提取**：利用参考语言模型（英文GPT-2-XL，中文Wenzhong-GPT2-110M）计算文本的困惑度、熵分布、爆发度等6项统计特征，由XGBoost分类器输出AI生成概率。

**语言学文体检测**：纯CPU运行的14维文体特征引擎，分微观（句子级9特征）、中观（段落级2特征）、宏观（全文级3特征）三个层次提取与语言模型概率正交的风格特征。

**编码器分类**：基于预训练语言模型（英文DeBERTa-v3-large，中文Chinese-RoBERTa-wwm-ext-large）的LoRA微调分类器，输出二分类概率。

**Binoculars零样本检测**：通过观察者模型和表演者模型的交叉困惑度比值进行零样本检测，无需训练数据。

**加权集成判定**：各阶段结果按语言特异性权重融合，权重支持动态归一化，当某些阶段不可用时自动调整剩余权重。

**文件上传检测**：支持PDF（PyMuPDF+pypdf双引擎）、TXT、Markdown文件上传，自动提取文本内容进行检测。

**分段检测**：对长文本按句子边界分割为最多8个段落，每个段落独立检测，展示文本中AI生成概率的空间分布。

**后台模型下载**：首次启动时自动下载Binoculars大模型（7B参数级别），支持断点续传，服务以降级模式运行直到模型就绪。

**Web前端**：提供双模式界面（文本粘贴 + 文件拖拽上传），显示综合判定、置信度、各阶段分数和分段检测结果。
