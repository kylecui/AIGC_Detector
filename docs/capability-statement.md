# 能力边界与使用指引

**版本**: 2026-08（依据W4/W4b实验、W5试批、FN-1案例与首份可辩护性计分卡）
**定位**: 本系统的承诺是**判定的可核查性与盲区透明**——每个结果附带分段证据与置信度，已知局限主动声明。检测分数是筛查辅助，**不是定性证据**。

所有数字均标注口径。部分数字来自小样本初步实验（标记 PRELIMINARY），随探针集扩充持续更新；全部数据可溯源至 `reports/` 与 `DETECTOR_NOTES_2026-08.md`。

## 二、已知盲区（边界清单）

| 盲区 | 证据 | 后果 | 建议替代 |
|---|---|---|---|
| **中文正式文书**（声明/公告/承诺书/情况说明/通报等固定格式文本） | 本项目双向实测：AI代写声明被漏判（置信0.89）；人工银行公告被误判（置信0.99）。人类侧误判率约20% [13%, 31%]（n=82）。**语料级检测（批量均值筛查）经本项目实验（2026-08-18）证实在此语域同样无效**：对合约生成的强模型文本，批量评分反而更低于人类语料（方向倒置），批量化会放大错误而非修复。**2026-08-21更新**：原始（未经编辑的）合约生成文本现可被Binoculars下限规则捕获（见正面清单），但人工编辑后文本仍在此盲区内 | **双向失效**：既漏判AI代写（编辑后），也误判人工文书。此语域用词与结构高度规范化，人写与AI写的文本在统计上天然相近，属于方法本身的限制 | 创作过程留痕等旁证（编辑后文本的唯一可靠路径）；人工复核 |
| **英文正式文书**（企业公告/召回通知/更正与解约声明等） | **本项目自测**（2026-08-20，35篇人类正式文书探针，89%为2023年前文档）：**71% [55%, 84%] 被误判为AI**，其中14篇置信度高于0.8（最高0.984）；召回通知、更正公告、解约声明类100%误判。公开研究（arXiv:2607.13044）与此一致 | 误判方向为主（人类正式文书被高置信标为AI）；与中文侧的漏判方向相反——同一语域在两条语言路径上以相反方向失效 | 此语域**完全避免**使用本系统判定；人工复核与过程留痕 |
| **过短文本**（<50字符） | 系统最低字符要求 | 不适用单文档判定 | 提供更多文本 |

系统会在响应中自动附带 `caveat`（正式文书提示）与 `segment_highlights`（局部AI痕迹）以辅助上述盲区的人工复核——见下文决策流程。

## 三、灰色地带（部分可靠，谨慎使用）

- **强模型生成的正式文书（即使未用固定模板约束）**：配对实验中，最强模型的自由生成正式文书均值检出分数仅0.26-0.33（n=40×2轮）——即约七成漏判。**在正式文书语域，盲区的边界是"语域"本身，不是"是否用了模板"**。
- **带固定格式约束生成的非正式文书**：实验显示中强模型在规格约束下逃逸检测的分数显著下降（合约臂均值0.31 vs 自由臂0.83，两轮复现）。任何"按格式要求生成"的文本都应降低对整体判定的信任。

## 四、审核者决策流程（拿到结果后怎么做）

按响应四要素逐步判断：

```
① 有 caveat（正式文书提示）？
   ├─ 是 → 整体判定只能作排序参考。进入②，不做自动定性结论。
   └─ 否 → 进入②

② segment_highlights（局部AI痕迹）最高分段 ≥ 0.8？
   ├─ 是 → 该段落人工复核优先级最高；核查段落原文与上下文。
   │        若为关键内容（结论/条款/数据），采信前必须有旁证。
   └─ 否 → 进入③

③ 置信度与判定方向
   ├─ 判AI + 高置信 + 非盲区语域 → 可作为筛查依据，采信前建议二次抽检
   ├─ 判Human + 高置信 + 正式文书语域 → 无效结论（盲区），转人工
   └─ 任何低置信 → 转人工或补充语料
```

**两类错误的代价不对称时**（例如学术诚信场景，误判AI伤害作者 vs 漏判AI损害评审）：
- 误判AI代价高 → 只采信"判AI+高置信+非盲区"，其余全部人工；
- 漏判AI代价高 → 整体判定仅作初筛，重要文书一律过程证据+人工复核。

## 五、FAQ

**Q1: 为什么主动声明盲区？这不是给想绕过检测的人指路吗？**
盲区对应的机制（固定格式文本的统计相近性）是公开学术文献早已论证、任何测评都能独立复现的事实；我们不声明它不会消失，只会让不知情的用户独自承担误判风险。声明边界+提供替代方案（人工复核/语料级/过程留痕），把不可消除的风险转化为使用者可管理的决策。

**Q2: 检测分数能作为"这是/不是AI写的"的证据吗？**
不能单独作为定性证据。本系统定位是**筛查与人工复核辅助**：分数用于排序预警与聚焦注意力，定性结论需要旁证（过程证据、语料级分析、人工审读）。

**Q3: 为什么在已知不可靠的语域仍然输出判定数字？**
数字附带警示与置信度，供专业人员做风险排序使用（例如从100份文书中挑出优先复核的10份）。完全不输出等于放弃辅助价值；关键是警示必须在场——这就是 caveat 字段的用途。

**Q4: 置信度本身可信吗？**
在一般语域基本可信；在正式文书语域**不可信**（初步校准误差偏高，见计分卡）。这也是该语域必须人工复核的原因之一。
